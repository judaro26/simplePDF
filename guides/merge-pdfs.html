Merge PDF files

Combine multiple PDFs into one document. SimplexPDF assembles the selected pages locally in your browser and downloads a new file.

Steps

  1. On the SimplexPDF tools page, choose Merge PDFs.
  2. Add at least two PDF files. The current tool accepts up to 10 files, each up to 50 MB.
  3. Arrange the order with the up-arrow controls. Remove any file you don’t want included.
  4. Select Merge PDFs. The merged result downloads as a new PDF.
  5. Open the result and check its page count, order, bookmarks, forms, and page appearance before sharing.

Tips for cleaner merged files

  • Name or order source files before choosing them so the sequence is easier to verify.
  • If a PDF is encrypted, damaged, or unusually structured, the merge may fail. Try a non-encrypted copy only if you’re authorized to create one.
  • Keep the originals: merged documents can have different page sizes, form behavior, metadata, and accessibility characteristics.
  • If a file is very large, close other browser tabs and ensure the device has enough available memory.
Privacy: This tool reads the selected files in the browser. The app does not upload document contents to a SimplexPDF processing server. Hosting providers may still process ordinary connection metadata.

What Merge does not do

Merge combines pages into one PDF; it does not OCR scanned pages, translate text, or guarantee that every form, bookmark, digital signature, or special PDF feature will remain interactive. Review the output in a PDF reader before relying on it.
