Page management

Split and organize PDF pages

Use page numbers and ranges to make smaller PDFs, extract selected pages, remove pages, or rotate a document.

Enter page ranges

Ranges are 1-based: page 1 is the first page. Separate individual page numbers and ranges with commas. For example, 1-3, 5, 8-9 means pages 1, 2, 3, 5, 8, and 9. The range must fit the document’s page count.

Split a PDF into page files

  1. Choose Split PDF on the tools page.
  2. Open one PDF, enter the pages to split, and run the tool.
  3. SimplexPDF packages the selected pages as individual PDFs inside a ZIP download.
  4. Extract the ZIP and check the resulting page files.

Extract selected pages into one PDF

  1. Choose Extract pages.
  2. Enter the pages or ranges you want, such as 2-4, 7.
  3. Run the tool and review the newly downloaded PDF.

Delete or rotate pages

  • Delete pages: enter the pages to remove. At least one page must remain.
  • Rotate pages: choose a clockwise, counterclockwise, or 180° rotation. The current rotate tool applies the selected angle to every page.
Keep an original copy. Deleting or rotating pages creates a new output file; check its page count and orientation before sharing. Some features in encrypted or malformed PDFs may not be preserved.

These operations run in your browser and do not send document contents to a SimplexPDF processing server. Browser memory use depends on the size and complexity of the PDF.
