Forms and signatures

Fill and sign an interactive PDF

SimplexPDF can fill standard interactive AcroForm fields and add a drawn signature as a visible annotation.

Fill interactive fields

  1. Open the PDF Editor and load the form PDF.
  2. Select Forms in the editor toolbar. If supported fields are present, the panel lists text fields, checkboxes, dropdowns, option lists, and radio groups.
  3. Enter values in the panel. Fields marked read-only cannot be changed in SimplexPDF.
  4. Optionally select Flatten fields in downloaded copy to make the field appearance non-interactive in the output.
  5. Choose Download PDF and check the result in a PDF reader before submitting it.

Add a drawn signature

  1. Choose Sign in the editor toolbar.
  2. Draw on the page using a mouse, touchpad, or stylus. Use Undo if you need to remove the last mark.
  3. Download the edited copy and inspect its placement.
A drawn signature is a visible page annotation, not a cryptographic digital signature or identity verification. Do not use it when a recipient requires a certificate-backed signature, audit trail, or a particular e-sign service.

Unsupported form types

The current form tool handles standard AcroForm widgets. XFA forms, scans/printed forms with no interactive fields, and some unusual PDF controls may not be detected or editable. The tool does not perform OCR or create new fillable form fields. If the panel reports no fields, use the Text tool to add visible text, or use another form/OCR tool if the form must remain structured.

Supported form updates are made in the browser; the application does not upload the document to a SimplexPDF processing server. Keep an original copy and inspect the output before sending it.
