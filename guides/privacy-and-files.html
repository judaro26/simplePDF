Privacy by design

How SimplexPDF handles files

The supported PDF tools run in your browser. This page explains what that means—and what it does not mean.

What happens to a selected document?

The browser reads the file you choose and uses local JavaScript libraries to process it. The current version has no SimplexPDF application endpoint for uploading, storing, or returning your document. When processing finishes, the browser creates a local download.

What may still be handled?

  • Your browser keeps the current file data in memory during the active page session. Downloaded files may remain in your Downloads folder or backups.
  • The website host, DNS, CDN, or security provider may receive ordinary request metadata such as an IP address, request time, requested assets, browser information, and security/error logs.
  • Browser extensions, device software, network monitoring, or backups operate outside SimplexPDF’s control.
  • The ad placements on this site are visual placeholders. No AdSense or analytics script is currently loaded. If advertising is activated, its providers and consent controls must be described before ads are served.

What local processing does not guarantee

It is not a security certification and cannot guarantee that files are safe from other software on the device. It does not ensure every tool works with every PDF. The editor’s whiteout and text replacement are visual overlays, not secure redaction; original content may remain extractable.

Use good document hygiene

  • Keep an untouched copy of important documents.
  • Review the output before sharing it.
  • Use a trusted, updated browser and device.
  • For confidential files requiring verified redaction, use a dedicated tool that actually removes and validates the underlying content.
