PDF Editor

Edit and annotate a PDF

Use the browser-based editor to change the visible wording of selectable text, add styled text, place an image, and mark up pages—without uploading the PDF to a SimplexPDF processing server.

Important: Text replacement covers the old text visually and draws a replacement. It may leave the original words extractable from the PDF. Whiteout is also only a visual cover. Neither feature is secure redaction.

Open a document

  1. Open the SimplexPDF Editor.
  2. Choose a PDF or drop one into the page. The editor accepts PDFs up to 50 MB.
  3. Wait for the page preview and text selection layer to load. Select pages from the left side.

Edit existing text directly on the page

  1. In Select mode, click a text run on the rendered page. If the PDF contains selectable text, an inline editing box appears over it.
  2. Type the replacement wording in that on-page box. Use the formatting bar to choose a font family, size, bold, italic, underline, color, or alignment.
  3. Click Done or press Command/Ctrl+Enter to finish. Download the PDF to create an edited copy.

The editor tries to reuse an embedded font when possible. If the original font is unavailable or cannot be embedded, it uses a close standard font. Position, font, color, and spacing matches are best-effort; review the downloaded page at normal and zoomed sizes.

If clicking text does not select it

The page may be a scan/image, the text may be outlined as vector shapes, or the PDF may use an unsupported encoding. This editor does not currently include OCR. Use the Text tool to add new wording or another OCR-capable application to recognize a scan.

Add new text and formatting

  1. Choose Text in the toolbar and click where the new text should begin.
  2. Type directly into the on-page text box. Set font family, size, emphasis, color, and alignment with the formatting bar.
  3. Click Done, then download the edited copy.

Insert an image

  1. Choose Images in the toolbar and select a JPG, PNG, or WebP image up to 20 MB.
  2. Click the page to place it. Drag the image to reposition it; drag its lower-right handle to resize.
  3. Download the PDF when the placement looks right.

Images are converted/prepared locally in the browser before being embedded in the output PDF. Large images can use substantial device memory.

Annotate, sign, or cover an area

Use Highlight to mark a region, Draw for freehand marks, Sign to draw a signature, Shape for a rectangle, or Whiteout to visually cover content. Use Undo to remove the most recent item on the current page.

Do not use Whiteout to conceal sensitive information. The original content may remain in the PDF’s text or image data. For sensitive removal, use a tool that performs and verifies true redaction.

What to check before sharing

  • Confirm the changed text fits and doesn’t cover nearby content.
  • Check every edited page, including pages outside the current view.
  • Keep an untouched original copy.
  • Remember that visual text replacement may leave original text searchable or extractable.
