Label your pages

Add a watermark or page numbers

Stamp visible text across pages or number pages in a PDF. SimplexPDF creates a separate output document.

Add a text watermark

  1. Select Add watermark from the tool list.
  2. Choose one PDF and enter the watermark wording, such as “DRAFT” or “COPY”.
  3. Choose Add watermark and download the new PDF.
  4. Open the result and inspect each page for legibility and placement.

Add page numbers

  1. Select Page numbers and open the PDF.
  2. Enter a format. Use {n} as the page number token; for example, Page {n}.
  3. Run the tool and check the numbering in the exported file.

Set document metadata

The Edit metadata tool can set the PDF title, author, and subject fields. Enter at least one value, save a new copy, and check the metadata in a PDF reader. Metadata editing does not remove all identifying content from pages, annotations, embedded files, or every other PDF field.

Watermarks are not access controls. A visible stamp does not encrypt a document or prevent copying. Do not use it as a substitute for password protection or secure redaction.
