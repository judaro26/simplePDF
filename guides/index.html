Not every PDF feature is available yet

OCR, compression, password protection, creating new form fields, and Office conversion are not currently implemented. We label unavailable tools instead of suggesting they work. The editor’s text replacement is a visual overlay; it does not reliably rewrite existing PDF text, and whiteout is not secure redaction.
